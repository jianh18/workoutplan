Training Checklist PWA

Files:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Deploy the whole folder to any static HTTPS host (GitHub Pages, Cloudflare Pages, Netlify, Vercel static hosting, etc.).
Then open the deployed URL in Safari on iPhone and use Share → Add to Home Screen.

All workout data is stored locally in the browser using localStorage.
Use the in-app Export JSON button for backups.
